# Generator Lookbook & Cataloage Foto - Brand Vestimentar

Aplicație web destinată echipelor de creație și marketing ale unui brand vestimentar pentru generarea rapidă a cataloagelor de prezentare (Lookbooks) și a albumelor de colecții.

## Funcționalități
- Încărcarea multiplă a fotografiilor de produs/ținută.
- Personalizarea titlului colecției (ex: *Colecția Toamnă-Iarnă 2026*).
- Selectarea stilului vizual al catalogului (Minimalist Editorial, Streetwear Dark, Classic Boutique).
- Adăugarea denumirii articolului, codului SKU și a prețului sub fiecare fotografie.
- Export direct în format PDF pentru distribuire către clienți sau tipar.
